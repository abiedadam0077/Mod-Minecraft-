# كيفاش تحمل وتشغل Craftly — خطوة بخطوة

## 1. المشروع والتحميل من GitHub

- [المشروع الكامل فالفرع ديال التطوير](https://github.com/abiedadam0077/Mod-Minecraft-/tree/arena/01a0e47b-mod-minecraft)
- [صفحة تحميل التطبيقات](https://github.com/abiedadam0077/Mod-Minecraft-/releases/tag/v1.0.0-preview)

فصفحة الإصدار، حل **Assets** وحمل:

- `craftly-explorer.apk`: التطبيق ديال المستخدم.
- `craftly-studio.apk`: التطبيق ديال الأدمن.
- `SHA256SUMS`: بصمات الملفات للتحقق من سلامتها، اختيارية للمستخدم العادي.
- **Source code (zip)**: المشروع كامل ديال هاد الإصدار؛ ماشي تطبيق قابل للتثبيت.

بديل لتحميل الكود: دخل لرابط الفرع، اضغط **Code → Download ZIP**. تأكد أن الفرع المختار هو `arena/01a0e47b-mod-minecraft`، لأن `main` ما تبدلش تلقائياً.

## 2. تثبيت التطبيقين على أندرويد

1. حمل ملفات APK من صفحة الإصدار الرسمية أعلاه.
2. افتح الملف من تطبيق الملفات أو من إشعار اكتمال التحميل.
3. إذا طلب Android السماح بالتثبيت من هذا المصدر، اسمح للمتصفح أو تطبيق الملفات اللي استعملتيه. من الأفضل تحيد هاد السماح من بعد التثبيت.
4. ثبت التطبيقين. خاص Android 8 أو أحدث.

هاد النسخ تجريبية موقعة بمفتاح debug، وماشي نسخ نشر نهائية للمتجر. ما تجربش تثبيت APK على iPhone: خاص نسخة iOS مختلفة.

## 3. شنو كيخدم من GitHub وشنو باقي خاصو سيرفر؟

**GitHub:** الكود، تحميل APK، تحميل كود الإصدار، والـActions اللي كيجمع التطبيقات.

**سيرفر HTTPS مستقل:** التسجيل والدخول، حساب الأدمن، رفع المودات والصور، المفضلة المتزامنة، التقييمات، وسجل التحميلات. فالتصميم الحالي ملفات المودات اللي كيرفع الأدمن كتتخزن فالسيرفر، ماشي تلقائياً فـGitHub.

GitHub Pages كيستاضف صفحات ثابتة فقط، وما كيخدمش Express/Node.js ديال هاد المشروع. رفع الكود إلى GitHub ما كيعنيش أن السيرفر ولى منشور. ما تكتب حتى GitHub token داخل APK أو فالكود العام.

## 4. نشر السيرفر

خاص خدمة كتقبل Node.js 22 أو Docker، ومعاها تخزين دائم وHTTPS. تقدر تختار مزود الاستضافة المناسب ليك؛ ما تم إنشاء حتى استضافة مؤدى عنها تلقائياً.

### إعدادات الخدمة

- المستودع: `abiedadam0077/Mod-Minecraft-`
- الفرع: `arena/01a0e47b-mod-minecraft`
- Build command: `npm ci && npm run build`
- Start command: `node server/index.js`
- Node.js: `22`
- المنفذ الافتراضي: `3001`، أو `PORT` اللي كتفرضو الاستضافة.

### Environment variables — كتدخلهم بشكل سري فلوحة الاستضافة

```text
NODE_ENV=production
ADMIN_EMAIL=بريدك-الإلكتروني
ADMIN_PASSWORD=كلمة-مرور-قوية-وخاصة-من-12-حرف-على-الأقل
DATA_DIR=/data/craftly
```

`/data/craftly` خاصها تكون مربوطة بـ **Persistent disk / Volume** قابل للكتابة. بلا تخزين دائم، الحسابات والمودات يقدرو يضيعو عند إعادة النشر. مسار التخزين يمكن تغييره حسب المزود. شغل نسخة واحدة من السيرفر فقط لأن قاعدة البيانات الحالية ملف JSON.

اختياري: `ALLOWED_ORIGINS` لتقييد الواجهات المسموح بها. خاصها تشمل عنوان الموقع و`https://appassets.androidplatform.net` ديال التطبيقين.

حساب الأدمن كيتخلق أول مرة فقط إذا ما كان حتى أدمن. تغيير متغير كلمة المرور من بعد ما كيعيدش تعيين كلمة مرور الحساب القديم. `.env` ديال جلسة التطوير ما مرفوعش لـGitHub لأنه سري.

من بعد النشر، افتح:

```text
https://عنوان-السيرفر/api/health
```

النتيجة المنتظرة: `ok: true` و`adminConfigured: true`.

إذا استعملتي reverse proxy، خاص حد الرفع يكون أكبر من 108 MB.

## 5. ربط التطبيقين

1. حل Craftly واضغط أيقونة الإعدادات اللي فوق.
2. فـ **Server address** دخل `https://عنوان-السيرفر` بلا `/api` وبلا مسار إضافي.
3. اضغط **Save & connect**.
4. دير نفس العنوان بالضبط في Craftly Studio.
5. دخل فـStudio بالبريد وكلمة المرور اللي حطيتي فإعدادات السيرفر.
6. فـCraftly أنشئ حساب مستخدم عادي.

## 6. نشر أول مود وتجربتو

1. فـStudio اضغط **Publish a mod**.
2. زيد الاسم والوصف والتصنيف وإصدار Minecraft وتقييم المحرر.
3. اختار صورة PNG/JPG/WebP أقل من 8 MB.
4. اختار ملف حقيقي ومجرب: `.mcaddon` أو `.mcpack` أو `.mcworld`، أقل من 100 MB.
5. أكد أن عندك الحق في توزيعه، ثم انشر.
6. أعد فتح Craftly أو عاود تحميل الكتالوج؛ غادي يظهر المود المنشور.
7. دخل للمود وحمله. من بعد اختار **Open in Minecraft**.
8. أكد الاستيراد داخل اللعبة وفعل الحزمة من إعدادات العالم إذا لزم.

Minecraft Bedrock خاصها تكون مثبتة ومتوافقة مع الملف. التطبيق ما كيقدرش يعدل ملفات اللعبة المحمية مباشرة. دير نسخة احتياطية للعوالم. الاستيراد داخل اللعبة باقي خاص يتجرب على هاتف حقيقي؛ اللي تحقق هو بناء APK ومسار الرفع والتحميل فالويب والـAPI.

البطاقات الستة الأولى مكتوب عليها Preview: هادو نماذج التصميم فقط وما فيهمش ملفات للتحميل. مودات Java بصيغة `.jar` ما مدعومينش.

## 7. تحديث APK من GitHub

دخل لتبويب **Actions → Build Craftly apps**. البناء كيبدأ عند رفع تغييرات للفرع ديال المشروع. إلا نجح، ملفات الاختبار كتكون فـArtifacts وفمجلد `releases/` ديال نفس الفرع.

صفحة GitHub Release إصدار ثابت؛ ما كتتحدثش بوحدها بكل build. خاص نشر إصدار جديد أو تحديث المرفقات بشكل مقصود. نسخ debug اللي تجمعات فـrunners مختلفين ممكن تختلف مفاتيح التوقيع ديالها؛ إذا رفض أندرويد التحديث، قد تحتاج تحذف النسخة السابقة أولاً (وهذا يمسح بيانات التطبيق المحلية). قبل التوزيع الحقيقي خاص مفتاح release ثابت ومحمي.
