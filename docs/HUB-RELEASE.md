# Craftly 1.4 — Hybrid Bedrock Content Hub

## التطبيقان
- **craftly-explorer.apk**: تطبيق المستخدم.
- **craftly-studio.apk**: تطبيق الأدمن.
- Android 8+، الإصدار 1.4.0 / versionCode 5، توقيع debug تجريبي.

## الجديد
- أيقونة C بنفسجية voxel بسيطة وواضحة. موارد Android adaptive جاهزة ومستخدمة في التطبيقين؛ ملفات iPhone/iPad/App Store جاهزة داخل المشروع، وليست نسخة iOS/IPA.
- Carousel لأحدث خمس إضافات حسب آخر نشر/تحديث، بطاقة وسطية وجوانب ظاهرة، سحب وأسهم ونقاط، معلومات المود والمفضلة والتفاصيل. بدون autoplay لتجنب الحركة غير الضرورية.
- Home: Latest Add-ons، Popular، Textures، Maps / Worlds، Shaders، Recently Updated. أقسام أفقية تتحمل عند الاقتراب منها، مع تحميل المزيد. الصور خارج أحدث خمس عناصر Lazy.
- Catalog موحد للمحتوى اليدوي والخارجي، مع source_type واضح، وبحث وفلاتر التصنيف والإصدار والتقييم والتنزيلات والجديد والتحديث والمصدر.
- Add Mod Manually مازالت موجودة. زادت حقول اختيارية للمبدع والوسوم وست screenshots ورابط HTTPS أصلي. رفع الملف اليدوي القديم والتنزيل والاستيراد لم يتبدلا؛ إذا توفر ملف ورابط معاً يبقى الملف هو زر التنزيل الأساسي.
- Content Sources: الحالة، آخر مزامنة ناجحة، العدد المستورد والجديد والمحدث والفاشل، تفعيل/تعطيل وSync now.
- Backend مصدره Supabase Edge Function: صفحات صغيرة، كشف التكرار، كاش metadata في قاعدة البيانات، صلاحيات، retry/backoff، حدود مزامنة، leases، حذف/حجب الاستيراد وإعداد Cron دوري.
- الملفات الخارجية **لا تُنسخ ولا يُعاد رفعها**. يظهر المصدر والمبدع وترخيص البيانات، وزر تحميل من المصدر يفتح الموقع الأصلي بموافقة المستخدم.

## مهم: الاستيراد التلقائي ليس مفعّلاً على مشروعك بعد

الكود والبناء جاهزان، لكن **لم تُنشر Migration/Edge Function/Cron على Supabase الخاص بك، ولم يتم ربط مصدر خارجي حقيقي أو استيراد محتواه**. لم تتوفر صلاحيات نشر أو مفاتيح وموافقات مصادر. لن تظهر حالة Connected وهمية.

النسخة تعمل مع المحتوى اليدوي القديم مباشرة. لتشغيل الميزات الموسعة والمزامنة:
1. شغّل `supabase/migrations/202609280001_hybrid_catalog.sql` فقط فوق قاعدة البيانات الحالية، بعد نسخة احتياطية. لا تعاود إنشاء الحساب أو إعداد الأدمن.
2. انشر `content-hub` وأضف أسرار المصدر داخل Supabase Edge Function Secrets، وليس التطبيق أو GitHub أو المحادثة.
3. أضف إعداد Vault وشغّل `supabase/schedule-content-sync.sql`، ثم فعّل المصدر المصرّح به من Studio.

الدليل الكامل والأوامر وعقد Feed: **[CONTENT-HUB.md](CONTENT-HUB.md)**.

## لماذا CurseForge معطّل افتراضياً؟

[شروط CurseForge الرسمية](https://support.curseforge.com/support/solutions/articles/9000207405-curse-forge-3rd-party-api-terms-and-conditions) تمنع حفظ/caching بيانات API بالشروط العادية. مفتاح API وحده غير كافٍ. لهذا يلزم إذن كتابي خاص بالتخزين قبل تفعيل هذا الموصل. البديل المجهّز هو Feed مرخّص من المبدع، مع تصريح فعلي باستعمال metadata والصور. لا scraping غير مصرّح به ولا مصادر وهمية ولا مفاتيح داخل APK.

## التحقق

اختبارات PostgreSQL/RLS الأصلية والجديدة، توافق الإضافة اليدوية، cache، validation، التصنيفات، منع الروابط الخطرة/Java، صفحات المصدر وretry نجحت. فحص TypeScript للـEdge Function نجح. اختبارات المتصفح تستعمل بيانات محاكية فقط، وتشمل الكتالوج القديم والجديد وcarousel والإسناد للمصدر والصور والفلاتر وحجب تفعيل مصدر بلا موافقة.

فحص Supabase الحقيقي قراءة فقط؛ لا يثبت نشر الـBackend أو نجاح sync أو رفع الملفات. بعد الإعداد، اختبر Feed صغيراً مسموحاً، ثم موداً يدوياً حقيقياً وتنزيله وفتحه في Minecraft على الهاتف.

احتفظ بالتطبيق مفتوحاً أثناء الرفع والتنزيل. التوقيع تجريبي وقد يتطلب حذف النسخة القديمة؛ احفظ ملفاتك المحلية أولاً. Supabase والحسابات السحابية لا تُحذف بإزالة التطبيق. النشر على المتاجر يحتاج توقيع إنتاج واختبارات الأجهزة ومتطلبات المتجر.
