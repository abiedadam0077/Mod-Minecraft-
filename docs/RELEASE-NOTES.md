## Craftly — نسخة تجريبية لأندرويد

جوج تطبيقات مربوطين بنفس السيرفر:
- **craftly-explorer.apk** — تطبيق المستخدم.
- **craftly-studio.apk** — تطبيق الأدمن.

### التحميل والتثبيت
حل **Assets** وحمل جوج ملفات APK. Android 8 أو أحدث مطلوب. **Source code (zip)** فيه كود المشروع كامل، ماشي تطبيق للتثبيت.

### التشغيل
[الدليل الكامل بالدارجة خطوة بخطوة](https://github.com/abiedadam0077/Mod-Minecraft-/blob/arena/01a0e47b-mod-minecraft/docs/START-HERE-AR.md)

خاص نشر السيرفر على استضافة HTTPS، ثم إدخال نفس عنوانه في إعدادات التطبيقين. GitHub يستاضف الكود وملفات APK، وليس سيرفر الحسابات ورفع المودات. لا توجد بيانات دخول سرية ضمن هذا الإصدار؛ أدمن الاستضافة يُنشأ بواسطة ADMIN_EMAIL وADMIN_PASSWORD.

### ملاحظات مهمة
- نسخ اختبار **debug-signed**، وليست نسخ متجر نهائية.
- APK مبني من المصدر `20f18ee0f195d9d5cf4e735d8fd9f714131fb44d`. التغييرات اللاحقة في هذا الإصدار تخص التغليف والتوثيق فقط.
- اختبارات الويب والـAPI وبناء Android نجحت. استيراد الملفات في Minecraft لم يُختبر على هاتف حقيقي بعد.
- البطاقات الأولية للمعاينة فقط. الأدمن يرفع ملفات Bedrock حقيقية ومصرح بتوزيعها.
- بعد التحميل، التطبيق يطلب موافقة المستخدم لفتح الملف في Minecraft؛ اللعبة تتحكم في الاستيراد والتفعيل.
