## 🔧 شنو تبدّل بالضبط؟

المشروع الأصلي فيه قيد (limit) ف ملف `AccountsManager.kt`:

```kotlin
private fun checkLimit(): Boolean {
    val circumventLimit = File(PathManager.DIR_FILES_EXTERNAL, "circumventLimit")
    return !circumventLimit.exists() && !isInGreaterChina() && !hasMicrosoftAccount()
}
```

معنى هادشي: إلا كنت **خارج الصين** وما عندكش **حساب مايكروسوفت مسجّل من قبل** فالبرنامج
كيدخل ف حالة «غير رسمي» (`isOffline`):

* زر **إضافة حساب** كان كيعطيك غير رسالة تقول لك «سير تسجل بحساب مايكروسوفت».
* ما كانش كيخليك تختار أي حساب (اختيار الحساب كان معطّل).
* وملي كتجي تشغّل اللعبة كان كيقول ليك «لا يوجد حساب».

### التعديلات اللي تدّار (3 ملفات فقط)

| الملف | التغيير |
|---|---|
| `.../game/account/AccountsManager.kt` | حذف `checkLimit()` كاملة — الحساب الحالي كيبقى دائمًا صالح للاستعمال، و `isOffline` كيبقى `false` دائمًا |
| `.../ui/screens/content/AccountManageScreen.kt` | زر «إضافة حساب» كيحلّ **القائمة الكاملة** (مايكروسوفت / **Offline** / سيرفرات Yggdrasil) + اختيار الحساب يولّي مفعّل |
| `.../ui/screens/content/elements/LauncherElements.kt` | ملي ما يكونش حساب، كيتحلّ مباشرةً منيو تسجيل الدخول الكامل بدل رسالة المايكروسوفت |

التعديلات موجودة كـ patches ف مجلد [`patches/`](patches) — يعني المشروع الأصلي ما تبدّلش،
كنزيدو عليه التغييرات وقت البناء.

**النتيجة:** كتبدل غير التطبيق، تكتب سميتك (Nickname) وكتلعب — بلا حساب رسمي وبلا إنترنت حتى.

## 📦 كيفاش تحصل على الـ APK؟

### الطريقة 1 — GitHub Actions (الأسهل، بلا أي برنامج على الحاسوب)

1. ف هذا المستودع سير لتبويب **Actions**.
2. اختار **«بناء APK معدّل — Zalith Launcher 2»** من اليسار.
3. دوس **Run workflow** واختار بنية المعالج:
   * `arm64` ← **أغلبية الهواتف الحديثة** (اختارها إلا ما كنتش عارف)
   * `arm` ← هواتف قديمة 32-bit
   * `x86_64` ← محاكيات/أجهزة معينة
   * `all` ← كل البنيات (البناء كيطول بزاف)
4. انتظر البناء (تقريبًا 20 – 60 دقيقة).
5. حمّل الـ APK من:
   * **Artifacts** (تحت اسم `zalith-offline-arm64`) — خاصك تكون داخل بحساب GitHub، أو
   * **Releases** ← الوسم `mod-offline-arm64` — تحميل مباشر من الهاتف.

### الطريقة 2 — البناء محليًا (Linux / macOS / WSL)

المتطلبات: **JDK 21** + **Android SDK** (+ إنترنت لتحميل NDK والمكتبات).

```bash
git clone https://github.com/abiedadam0077/Mod-Minecraft-.git
cd Mod-Minecraft-
./scripts/build-apk.sh arm64        # أو: arm / x86_64 / all
```

السكريبت كينزّل `ZalithLauncher2` الأصلي، كيطبّق التعديلات، ومن بعد كيبني الـ APK.
الملف كيتلقى ف: `upstream/ZalithLauncher/build/outputs/apk/debug/`

> الـ APK هنا من نوع **debug**: كيتثبّت بجانب النسخة الرسمية (المعرّف كينتهي بـ `.debug`)،
> ما كيمسحش الداتا ديالك، وما كيحتاجش مفاتيح توقيع سرية.

## 📲 التثبيت و إضافة حساب غير رسمي

1. حمّل الـ APK وثبّتو (خاصك تفعّل «تثبيت من مصادر غير معروفة» إلا طلب منك).
2. حلّ البرنامج ← **إدارة الحسابات** (Account Manager).
3. دوس **إضافة حساب** ← اختار **Offline / حساب محلي**.
4. كتب الاسم (Nickname) — واختياريًا الـ UUID إلا بغيت تكمل بنفس الشخصية ديالك ف لانشر آخر.
5. رجّع للشاشة الرئيسية، اختار نسخة ماينكرافت وحدّد مسار اللعبة (`.minecraft`)، ودوس **تشغيل** 🎮

### كيفاش تتأكد أنك ركّبت النسخة المعدّلة؟

* ف سجل البرنامج (Logs) كتلقى السطر: `MOD_ZALITH_OFFLINE_ACCOUNTS: account restrictions are disabled`
* وزر **إضافة حساب** كيحلّ ليك القائمة الكاملة (فيهاخيار الحساب المحلي / Offline)، ماشي غير رسالة المايكروسوفت.

## ⚠️ ملاحظات مهمة

* هاد التعديل كيحيّد قيدًا تقنيًا فرضتو النسخة الأصلية على المستعملين خارج الصين.
  **الأصل ديما هو لعبة مدفوعة** — إلا قدرت، شريها من الموقع الرسمي باش تدعم Mojang والمطوّرين.
* الحساب غير الرسمي **ما كيخدمش** ف السيرفرات الرسمية (Online-mode) بحال Hypixel —
  هادوك خاصهم حساب مايكروسوفت أصلي. ولكن كيخدم مزيان ف اللعب الفردي (Singleplayer)
  وف السيرفرات غير الرسمية (Offline-mode / LAN).
* ف هاد البناء تسجيل الدخول بحساب **مايكروسوفت معطّل** (حيت مفاتيح OAuth ديال المطوّر ما كايناش)،
  إلا بغيت تفعّلو: حط المفتاح ديالك ف ملف `upstream/.oauth_client_id.txt` قبل البناء.
* إلا فشل `git apply` من بعد تحديث المشروع الأصلي: بدّل قيمة `upstream_ref`
  (أو `ZALITHLAUNCHER2_COMMIT`) ل المرجع الموجود ف `UPSTREAM_COMMIT`.
